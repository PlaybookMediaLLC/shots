Shots brings visual creation, release qualification, launch planning, approvals, and scheduled publishing into one workspace. Every step follows two core rules: **claims must be grounded in evidence**, and **a human approves before anything publishes**.

## Setup Sequence

- [Quickstart](/docs/getting-started/quickstart)
- [Workspace Setup](/docs/getting-started/workspace-setup)
- [Plans & Credits](/docs/getting-started/plans-and-credits)

## What You Need Before You Start

1. **A Shots workspace on a paid plan** — Pro, Business, or Enterprise (there is no free plan). See [Plans & Credits](/docs/getting-started/plans-and-credits).
2. **Your product profile and brand kit** — configured in **Settings → Product** and **Settings → Brand voice & visual kits** so generated briefs and screenshots match your product and visual identity.
3. **Optional integrations** — GitHub repositories for [Automate workflows](/docs/automate), social accounts in **Settings → Channels**, or workspace API keys in **Settings → Developer API**.
