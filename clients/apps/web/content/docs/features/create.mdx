## Summary

**Create** (`/create`) is the hub for every visual studio in Shots, anchored by the **Screenshot Editor** (`/editor`). Drop in any screenshot or capture a live URL to frame it on brand, apply shadows and 3D perspective, animate with keyframes, and export clean PNG, JPEG, WebP, MP4, WebM, or GIF files with no watermark.

Every visual generated by a Shots launch campaign is stored as a real editor project so your team can open and refine every layer by hand.

## Capabilities

| Capability | Details |
| --- | --- |
| Backgrounds | Gradient, mesh, pattern, solid, and image backdrops plus brand-kit presets |
| Browser & window mockups | Safari, Chrome, and Arc browser frames (light and dark) with editable URL bar text, plus macOS window chrome |
| 3D perspective & shadows | Interactive tilt, rotation, depth, corner radius, padding, and layered drop shadows |
| Text & image overlays | Custom typography layers, badges, callouts, and brand logos |
| Keyframe animations | Built-in animation presets, multi-slide timelines, and in-browser MP4, WebM, and GIF encoding via FFmpeg WASM |
| Tweet to image | Import a public post from X (`/create/tweet`) and style it for sharing |
| High-resolution export | Export up to 4x scale with client-side editing and optional server-side Sharp optimization via `/api/export` |
| Direct handoff to Publish | Send finished visuals straight into a **Publish** draft without leaving the editor |

## Sub-Views in Create

- **New (`/create`):** Launch a Screenshot, Canvas, Story Set, Store Screenshots project, or Code image.
- **Recent (`/create?view=recent`):** Reopen recently saved projects.
- **Templates (`/create?view=templates`):** Start from workspace or preset layouts.
- **Tools (`/create?view=tools`):** Access the in-app [Image & Video Tools](/docs/features/image-tools).
