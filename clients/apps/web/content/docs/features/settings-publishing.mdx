## Summary

The **Publishing** and **Integrations** groups in Settings connect Shots to external networks, developer tools, and AI agents.

## Publishing Sections

| Section | Route | What it controls |
| --- | --- | --- |
| **Settings → Profiles** | `/settings/publishing-brands` | People and company identities you post as; each profile has General, Scheduling (posting queue slots & time zone), New draft defaults, Public profile, and Writing Assistant settings |
| **Settings → Channels** | `/settings/channels` | Connect, reconnect, or disconnect social accounts (X, LinkedIn, Instagram, Bluesky, Mastodon, and more) and assign each account to a profile |

## Integrations Sections

| Section | Route | What it controls |
| --- | --- | --- |
| **Settings → Integrations** | `/settings/integrations` | Overview of connected apps and external services (such as GitHub, Senja, and notification integrations), required permissions, and setup status |
| **Settings → Agents & API keys** | `/settings/ai-agents` | Create scoped workspace API keys or approve OAuth connectors for Claude, ChatGPT, Codex, OpenCode, Grok, Grokbot, OpenClaw, Hermes, Cursor, Gemini, Muse, the Shots CLI, and any MCP client — see [Connect AI Agents](/docs/agents) |
