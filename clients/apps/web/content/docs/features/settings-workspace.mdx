## Summary

Opening **Settings** (`/settings`) switches the sidebar into Shots' grouped settings navigation. Settings are organized by owner—your personal account first, followed by workspace-wide controls.

## My Account

| Section | Route | What it controls |
| --- | --- | --- |
| **Settings → Founder Hub** | `/settings/founder-hub` | Founder Hub desktop preferences, connected computers, and meeting settings |
| **Settings → Account** | `/settings/account` | Display name, sign-in email, active sessions, and account deletion |
| **Settings → Notifications** | `/settings/notifications` | Activity preferences, email delivery channels, and Slack notifications |
| **Settings → Appearance** | `/settings/appearance` | Light/dark theme, sidebar navigation layout (expanded, compact, dynamic), calendar defaults, and editor direction |
| **Settings → Security** | `/settings/security` | TOTP two-factor authentication enrollment and session controls |
| **Settings → Install** | `/settings/install` | Install Shots as a progressive web app on desktop or mobile |

## Workspace & Team

| Section | Route | What it controls |
| --- | --- | --- |
| **Settings → General** | `/settings` | Workspace name, slug, logo, time zone, release preferences, and defaults |
| **Settings → Billing** | `/settings/billing` | Active plan (Pro, Business, Enterprise), invoices, payment method, and AI credit packs |
| **Settings → Members** | `/settings/members` | Invite, manage, and remove workspace members |
| **Settings → Roles** | `/settings/roles` | Review Shots' built-in workspace roles and least-privilege permissions |
| **Settings → Voice notes** | `/settings/voice-notes` | Enable voice notes, audio upload, draft generation, and voice command settings |
| **Settings → Experimental** | `/settings/experimental` | Opt in to preview capabilities before general availability |

## AI & Agents

| Section | Route | What it controls |
| --- | --- | --- |
| **Settings → Models & usage** | `/settings/ai-models` | Workspace AI toggle, per-surface default model tiers and reasoning effort, and monthly credit gauges |
| **Settings → Instructions** | `/settings/ai-instructions` | Standing workspace instructions layered beneath brand voice and prohibited terms |
| **Settings → AI agents** | `/settings/ai-agents` | MCP server URL, OAuth and API-key agent connections, plugin/skill installers, and tool scopes |
