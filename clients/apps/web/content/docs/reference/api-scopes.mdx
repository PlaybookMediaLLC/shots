## Scope Selection Guidance

- Start with read-only (`artifact:read`) when testing a new integration.
- For CI/CD release intake, combine `release:create`, `upload:sign`, and `asset:write`.
- Reserve `post:publish` and `post:delete` for explicitly trusted automation; on OAuth consent screens, these two scopes are never pre-selected even when a client requests them.
- Rotate or revoke keys immediately in **Settings → Developer API** or **Settings → Agents & API keys** if a credential is exposed.
