Shots includes dedicated visual studios for developer-focused code graphics and mobile app store listings.

## Creating Code Visuals in Code Studio

Open **Create → Code image** (`/create/code`):

1. **Paste code or import from GitHub:** Paste a snippet, switch to diff mode, or paste a GitHub file URL (with line numbers), pull request, commit, or gist.
2. **Focus the reader's eye:** Highlight changed lines, dim surrounding context, add inline annotations, and enable file tabs or terminal chrome.
3. **Apply your brand theme:** Pick a built-in syntax theme or a theme generated from your [brand kit](/docs/guides/brand-kit-and-visuals).
4. **Export or post directly:** Export PNGs, a multi-slide LinkedIn PDF carousel, or an animated MP4/WebM/GIF video—or click **Post this** to open a **Publish** draft with the visual attached and the code populated as alt text.

## Building App Store & Google Play Sets

Open **Create → Store screenshots** (`/create/store`):

1. Choose your target device dimensions and arrange multi-slide screens side by side.
2. Drop in raw simulator or device captures; Shots frames them inside matching mockups with consistent padding and shadows.
3. Add headlines and callouts using your brand typography, save the project to **Library → Store screenshots**, and export the complete set at store-ready resolution.
