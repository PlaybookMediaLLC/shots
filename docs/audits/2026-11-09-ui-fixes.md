## Reuse and scope

- **Reused:** existing UI primitives, local-time resolver, versioned mutations, navigation guards, settings requests/queues, worker processing, FFmpeg loader, project pagination, and analytics CSV rules.
- **New:** `lib/csv.ts` extracts behavior for two existing exporters; no dependency was added. Stateful regression tests use the existing React/JSDOM and Playwright frameworks.
- **Affected:** web UI and browser-side lifecycle owners, their existing consumers, and tests. No backend API, schema, authorization, tenancy, or publishing contract changed.

- `npm run quality:check` in `clients/`: passed. Formatting, ESLint with zero allowed warnings, workspace type checks, 1,518 web tests, 23 editor-package tests, and 12 collaboration tests passed (one existing environment-dependent collaboration test skipped).
- Focused UI state suite: 29 passing tests covering time/color controls, save ordering, polling failures/cancellation, onboarding draft/focus, navigation, queue cleanup/savings, analytics export races, and worker startup replacement.
